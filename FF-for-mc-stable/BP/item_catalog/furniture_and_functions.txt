Furniture & Functional Items Documentation
=========================================

---

Electronics & Utility
---------------------

Plasma TV / Rustic TV
- Example IDs: plasma_tv, wooden_rustic_oak_tv, etc.
- Detects the weather and displays a different animation for each weather type.
- Can be turned on/off by interacting.
- Must be connected to an outlet to function.
- Customizable with paint tool (16 colors).
- Craftable in the crafting table.
- Available in multiple wood types (for rustic variant).

Ceiling Lamp / Table Lamp
- Example IDs: ceiling_light_oak, lamp_off_oak, etc.
- Can be turned on/off, emits light when on.
- Customizable with paint tool (16 colors).
- Available in all wood types.
- Craftable in the crafting table.

Ceiling Fan
- Example IDs: wooden_ceiling_fan_oak, etc.
- Decorative, can be placed on the ceiling.
- Available in all wood types.

Outlet
- Example ID: outlet
- Used to power electronic furniture (TVs, lamps, etc.).
- Has different states and effects.
